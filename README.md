# aws-scripts
Scripts I wrote and used as AWS Cloud Engineer



# AWS-IAM-IdentityCenter/iam-idc-inventory

1. Update the variables: REGION, IDENTITY_STORE_ID, and CUSTOMER_NAME
2. Run both python scripts. Each of them will output a file, which can then be use for inventory/reporting.


# EBS/Re-encrypting Volumes from AWS-managed Key to Customer-Managed KMS Key

1. Update the variables: REGION and NEW_KMS_KEY_ID
2. Input instance-id as argument when executing the script.
